# Game 01 – Snake

A classic Snake game built with [Godot Engine 4.6](https://godotengine.org/).

> **AI-assisted project.** This game was developed with AI assistance as the first entry in a series of small Godot game projects.

---

## How to Play

| Input | Action |
|-------|--------|
| Arrow keys or WASD | Move the snake |
| Enter / Space | Restart after game over |

Eat the red food to grow and increase your score. Avoid running into yourself.

## Tech

- **Engine:** Godot 4.6
- **Language:** GDScript
- **Renderer:** Forward Plus (D3D12 on Windows)
